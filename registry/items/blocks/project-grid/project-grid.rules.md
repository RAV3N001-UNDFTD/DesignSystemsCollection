# project-grid — AI 使用规则

## 何时用
- 作品集/项目列表页的项目卡片栅格。数据驱动（传 `projects` 数组），不要手写重复卡片。

## 何时不用
- 少于 3 个项目 → 用纵向堆叠的大卡片（信息更充分），栅格会显得空。
- 需要筛选/排序/分页的大型列表 → 这是展示型 block，列表管理另建数据表格模式。

## 组合约束
- 每个项目 tags 超过 3 个自动折叠为 "+N"（已内置），不要通过 className 放开。
- `aiAssisted` 是 ai badge 的唯一入口——不要在 tags 里手写 "AI" 标签冒充。
- 整卡可点（外层 `<a>`），卡内不要再嵌套链接或按钮。

## 可访问性
- 卡片链接的可访问名来自卡内标题文本，`href` 必须是真实可导航地址。
- hover 效果（阴影+标题变色）不是唯一的可交互提示：焦点态 ring 已内置，禁止移除。
